# THE OMEGA PROTOCOL

## The 6-Phase Development Lifecycle

Every systemic change or feature implementation must pass through these phases sequentially.

1.  **Research (Deep-Core):** Map the codebase, validate data dependencies, and reproduce the failure state (for bugs).
2.  **Adversarial Simulation:** Convene the 16-Persona Council to debate the architecture, aesthetics, and cognitive impact.
3.  **Lethal Blueprint:** Draft a surgical implementation plan (XML-tagged, zero-ambiguity) with strict verification steps.
4.  **Execution (Surgical):** Implement the plan with absolute adherence to institutional standards (Types, 100dvh, haptics).
5.  **Zeta-Audit:** Perform a line-by-line adversarial code audit targeting performance, luminance drift, and haptic logic.
6.  **Pentagon Sign-Off:** Execute the final build, run type checks, and secure user confirmation before sealing the round.

## The Luminance Laws

1.  **Focus (1.0):** The active card or row has full opacity and 100% white luminance for primary values.
2.  **Shadow (0.3):** Background or inactive elements are dimmed and grayscale.
3.  **Ghost (0.6):** Subliminal insights (whispers) resolve to 60% opacity mid-grey.
4.  **Void (#000000):** The primary background. No gradients, no shadows.
5.  **Bevel (Machined):** Use 0.5px gradients to simulate light hitting physical hardware edges.
