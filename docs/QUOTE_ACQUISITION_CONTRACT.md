# Bounded quote acquisition and attempt evidence — packet 16

This connects the packet-14 capture/constructor and packet-15 private storage. It adds durable attempt events, including zero-response failures, and a real HTTP adapter tested with injected synthetic transport. No provider credentials or real market requests are needed for acceptance. All results remain provisional; price qualification, revision policy and research acceptance remain separate requirements.

## Attempt event schema and writer

New pure module `src/research/quote_attempt.py` owns event construction/validation and the runtime source manifest. New central writer `archive_quote_acquisition_event(event: Mapping[str,Any]) -> dict[str,Any]` validates before client access and calls `append_quote_acquisition_event(p_event_sha256 text,p_unsigned_json text)`. It sends canonical_json of all event fields except event_sha256; the hash is SHA-256 of those exact UTF-8 bytes. Limit unsigned events to 64 KiB in Python and SQL. Receipt fields are exactly `event_sha256`, `attempt_id`, `sequence`, `inserted` (bool); all must match input, with integer sequence never bool.

Exact event fields: version=quote-acquisition-event-v1; attempt_id (canonical lowercase UUID string); sequence (integer 0..10001); previous_event_sha256 (null or hash); kind (started/page_saved/finished); occurred_at (canonical aware UTC ISO); pair; instrument; window_start_ns; window_end_ns; implementation_sha256; client_version=fxregime-quote-http-v1; runtime_manifest_json (string only on started, null otherwise); limits (object below); capture_sha256 (hash only on page_saved, null otherwise); snapshot_sha256 (optional hash only on finished); status (running on started/page_saved, complete or failed on finished); reason (null on started/page_saved, fixed code on finished); event_sha256. There are no raw errors, credentials, URLs, opaque cursors or freeform failure text in events.

Limits exact fields: max_pages (1..10000, default 200), max_page_bytes (1..16777216, default 16777216), max_total_bytes (1..268435456, default 67108864 and >= max_page_bytes), deadline_seconds (1..3600, default 300), request_timeout_seconds (1..60, default 30). All are actual integers, never bool. They are frozen across an attempt. The deadline bounds network work/iteration using monotonic elapsed time; synchronous archive operations use their database-client timeouts and must never be cancelled midway just to claim a hard end-to-end deadline. Check budget before further network work and after parsing/storage returns. This limitation must be explicit in the report.

Terminal reason codes: completed, request_failed, read_failed, body_limit, byte_budget, page_limit, time_budget, http_status, invalid_response, capture_invalid, capture_write_failed, page_event_write_failed, snapshot_write_failed, cursor_cycle, clock_invalid, implementation_changed. status=complete requires reason=completed; failed requires a different code. DB write failure may prevent the terminal event itself from being recorded; in that case raise a sanitized error and preserve the started/prior events as unfinished evidence. Never claim durable terminal success without a verified receipt.

`make_quote_acquisition_event(common: Mapping[str,Any], *, sequence:int, previous_event_sha256:str|None, kind:str, occurred_at:datetime, capture_sha256:str|None=None, snapshot_sha256:str|None=None, status:str='running', reason:str|None=None) -> dict[str,Any]` builds and validates a detached hashed event. Common exact fields: attempt_id,pair,instrument,window_start_ns,window_end_ns,implementation_sha256,client_version,runtime_manifest_json,limits. The helper sets runtime_manifest_json to null on non-start events. `validate_quote_acquisition_event(event:Mapping[str,Any])->None` checks local shape/hash/type/phase/identity rules; SQL adds cross-event truth.

## Runtime provenance

`quote_runtime_manifest() -> tuple[str,str]` returns (canonical manifest JSON, SHA-256 of it). It reads the exact on-disk bytes of these fixed repo-relative files: pipeline/src/research/quote_acquisition.py, quote_attempt.py, quote_capture.py, quote_reference.py, and pipeline/src/db/writer.py (all paths fully prefixed in the manifest). Exact manifest fields: version=quote-runtime-manifest-v1, client_version=fxregime-quote-http-v1, files (object mapping the five exact paths to lowercase SHA-256), dependencies (object with python and aiohttp version strings). No absolute paths, environment values or credentials. Source must exist; no guessed fallback hashes. Versions come from the executing Python and installed aiohttp distribution. Each label is a nonempty ASCII version token of at most128 characters with letters/digits/dot/underscore/plus/hyphen. Hash again before final completion; a changed manifest causes a failed implementation_changed attempt. This binds observed disk artifacts and dependency versions, not a cryptographic attestation of unmodified in-memory execution. SQL verifies manifest bytes/hash/shape; it cannot certify executed code.

## Durable event ledger

Forward migration 20260927000009_quote_acquisition_events.sql adds private append-only quote_acquisition_events with primary key(attempt_id,sequence), unique event_sha256, authoritative unsigned_json TEXT and inspectable document JSONB plus derived kind/occurred_at/stored_at. Fixed search path, RLS, explicit service-role SELECT/RPC-only access, no public/helper execute, and owner UPDATE/DELETE/TRUNCATE refusal follow packet15. No unrelated table writes or grant changes.

The RPC serializes each attempt (transaction advisory lock or equivalent), checks the exact text/hash and event contract, rejects future occurred_at, and enforces sequence 0 started with null previous hash. Every later event follows the exact preceding hash and immutable common identity/provenance/limits, has nondecreasing occurred_at, and cannot follow finished. An exact retry returns inserted=false even after terminal completion; same attempt/sequence with a different hash rejects. New execution with an existing started receipt must not launch another provider request; recovery is separate work, not an implicit restart.

page_saved at sequence N requires an existing capture with page_index=N-1 and matching pair/instrument/window. Its request must be >= the immediately preceding event occurred_at (started for the first page, previous page_saved thereafter), and its receipt must be <= the current event occurred_at. This prevents a new attempt from attaching captures requested before its start or before the preceding page acknowledgement. Each acknowledged capture raw_size_bytes must fit max_page_bytes, and the sum of acknowledged capture sizes must fit max_total_bytes. SQL checks these stored sizes; it does not infer unobserved network bytes or elapsed execution. Only page_saved events may intervene between started and finished. The terminal sequence is acknowledged_page_count+1. A terminal snapshot, if supplied, must already exist, have the exact ordered capture list from that attempt's page_saved events, matching pair/window, implementation hash/client version, and as_of<=occurred_at. Complete requires a snapshot whose acquisition_complete is true; failed may retain a diagnostic snapshot. Zero-response failed attempts have null snapshot. No complete/failed event is a qualification or evaluation permission.

## HTTP orchestration interface

Worker module `src/research/quote_acquisition.py` exposes async `acquire_quotes(*, pair:str, day:date, api_key:str, attempt_id:str, limits:Mapping[str,int]|None=None, transport:QuoteTransport|None=None, now:Callable[[],datetime]|None=None, monotonic:Callable[[],float]|None=None, persist_event:Callable|None=None, persist_capture:Callable|None=None, persist_snapshot:Callable|None=None) -> dict[str,Any]`.

Default persistence calls only central writer functions; injected callbacks let tests observe ordering. Default clocks are UTC now and time.monotonic, injected for deterministic tests. Pair locked, day is an actual date (not datetime), >=1970-01-01 and strictly before current UTC date. Require nonblank string api_key <=512 characters; never retain/log it. Validate request, clocks, limits and real runtime manifest before archiving a started event. If started cannot persist, or its receipt says inserted=false, perform no HTTP request. Invalid caller input raises ValueError before persistence/network.

`QuoteTransport` protocol has async `open_page(url:str, *, params:Mapping[str,str], timeout_seconds:float) -> QuoteResponse`. `QuoteResponse` has integer status, headers:Mapping[str,str], async `iter_chunks()` yielding bytes, and async `close()`. Default adapter uses aiohttp with TLS verification, no redirects, no ambient proxy/netrc auth, no cookie persistence and no automatic request retries. It owns/closes its session; injected transport ownership stays with the caller. Every response is closed on all paths. Requests always target https://api.massive.com/v3/quotes/{explicit locked instrument}; never navigate a returned next_url. Initial parameters match packet14 plus apiKey. Continuations use only cursor plus apiKey. Obtain the opaque cursor from the original validated response, verify its SHA-256 equals captured next_cursor_sha256, then request it at the fixed endpoint. Never store the cursor itself. A repeated next cursor stops with cursor_cycle.

Use asyncio timeout/wait_for around opening and each awaited chunk read with the smaller of per-request timeout and remaining overall network budget. Count actual received bytes, enforcing page and total caps before extending buffers. Oversize, interrupted or timed-out bodies are not misrepresented as complete captures; record the failed attempt and already saved prefix. Receipt time is taken after complete body receipt and before JSON parsing. Pass api_key as a configured secret to capture_quote_page. A non-200 response can be captured as failed-response evidence before stopping. Capture issues or bad status/schema stop traversal; no OHLC is constructed from an incomplete prefix.

For each complete response: capture -> durable archive_quote_capture -> durable page_saved event -> only then next HTTP request. If capture persistence or page event persistence is uncertain/fails, stop; do not fetch another page or claim the uncertain write absent. Terminal snapshot construction/persistence uses acknowledged pages only. If no acknowledged page, keep snapshot null. If a terminal snapshot fails, record snapshot_write_failed if the event store remains available. Return the verified terminal event (including its event_sha256) only after its receipt is checked. Never expose raw exception messages or credential-bearing error chains. On inability to record terminal, raise generic RuntimeError from None. Deliberate cancellation should close response/session, preserve prior durable progress, and propagate cancellation rather than fabricate completion.

The normal successful endpoint is complete retrieval of a provisional snapshot, not accepted market evidence. Completed empty quote results are still complete retrieval with no price. Per-request timeout, clock regression, exhausted page/byte/time budget and partial stream cases must remain explicit. No silent fallback provider, interpolation or live strategy publication.
