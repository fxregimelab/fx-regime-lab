# Quote snapshot reconciliation — packet 17

Compare immutable captured evidence without rewriting either snapshot or inferring provider event identity. This pure comparison is a required input to the later append-only qualification/revision policy; it does not implement that policy or qualify a price. All three locked pairs are supported separately. No network or database is needed.

## Public interface

`reconcile_quote_snapshots(*, before: Mapping[str,Any], before_pages: Sequence[Mapping[str,Any]], after: Mapping[str,Any], after_pages: Sequence[Mapping[str,Any]], as_of: datetime) -> dict[str,Any]` in `src/research/quote_revision.py`.

Each envelope has exactly snapshot_sha256 and unsigned_json, taken from the authoritative stored snapshot text. Verify exact UTF-8 SHA-256, lowercase hex, unsigned size <=1 MiB, strict JSON with no duplicate keys/nonfinite values, and exact snapshot fields version,implementation_sha256,client_version,reference. Match the existing quote-snapshot-v1 envelope version and client/hash format. Preserve accepted noncanonical outer whitespace by hashing original text, not a reserialization. No caller-supplied document may replace that text.

Validate every supplied page with validate_quote_page before interpretation. Require 1..10000 pages per side and a sum of original raw_size_bytes <=268435456 per side; reject above this explicit resource ceiling before parsing bodies. Also preflight actual body_text UTF-8 size before any validator parses it: <=33554432 bytes per page and <=536870912 bytes per side. Original raw-size assertions do not bound the actual sanitized representation. Both kinds of bounds must pass; a complete diff is never silently truncated. Recompute build_quote_reference at the snapshot reference's canonical aware UTC as_of. Require exact typed structural equality with its reference, including input/capture fingerprints, counts, flags, values and exclusions. Booleans/numeric-looking strings/floating counters cannot pass as integers. Reference as_of must be canonical UTC datetime.isoformat; caller as_of must be aware, normalized to UTC. Require before reference as_of <= after reference as_of <= comparison as_of. Require identical pair, instrument, UTC window, series_id and algorithm_version. Different implementation hashes are allowed and disclosed, never mistaken for a provider correction.

Neither argument nor nested input objects may be mutated. No clocks, randomness, environment, filesystem, credentials, external I/O, pandas or database imports. No imported private constructor helpers; use its public constructor and public capture serializer/validator.
