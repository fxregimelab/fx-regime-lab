# Private historical release-clock audit

Owner scope, 1 October 2026. Advance historical fundamental research by capturing explicitly named first-party release archives. Support US Federal Reserve FOMC statements and US BLS CPI releases only. A source-stated release clock is stronger evidence than an observation date, but it does not prove actual transmission time, provider ingestion or contemporaneous receipt. Keep those fields separate and unknown unless independently observed. No historical feature, forecast or trade qualification is added by this packet.

Each request names one supported source and a canonical release date no later than today. Build only the corresponding official archive URL; never accept arbitrary URLs, redirects or a current-release substitute. Bound an invocation to twelve distinct requests and each response to two megabytes. Preserve original successful, blocked, failed and truncated bodies with immutable receipts and hashes. Cache reuse checks request identity, path, receipt, body length and hashes. Recompute saved audits from original responses. Conflicting same-source/date releases fail that source; equal duplicates count once. Missing dates are not filled.

For FOMC, require the exact statement title, matching publication date, one source-stated `For release at` clock with explicit EST or EDT, and one unambiguous federal-funds target-range sentence. Parse whole, decimal and mixed-fraction bounds without arithmetic shortcuts. Check finite ordered percentages. Convert the clock using America/New_York and reject an EST/EDT label inconsistent with that date. Preserve the original clock and target-range wording. An announced target range is not a two-year sovereign yield, a realized effective overnight rate or a cross-country carry spread. Effective implementation date is unknown without the separate implementation note.

For CPI, require the archived release's own embargo header, matching release date, exact covered observation month and one unambiguous headline CPI-U month-on-month seasonally adjusted and year-on-year unadjusted percentage. Store each adjustment/period/unit separately. Do not mix those changes with a seasonally adjusted index level or a core/CPI-W figure. ET maps to America/New_York for that named date. A release's next scheduled publication clock does not replace its current embargo clock. Reject missing/ambiguous fields or a body whose release clock is after receipt. A blocked HTTP response remains unavailable; browser/search-reader text cannot masquerade as an original successful HTTP response.

A cutoff audit accepts an offset-aware decision timestamp and shows only captured source-stated releases strictly before that cutoff. Equality is excluded. This is a chronology control, not a certification of actual information arrival. Calendar-date-only decisions are rejected. Source-stated timing, current receipt, actual historical receipt, provider availability, effective policy date and expectations remain distinct. No surprise can be calculated without separately timestamped consensus.

Add a separate dashboard/report view with original dates, local clock/timezone, UTC conversion, released measures, source failures and missing currency legs. Existing pair research, bid/ask/vintage audits, saved AI and trade qualification must remain identical. Dashboard refresh only reads saved evidence. Offline replay reconstructs this audit without network or AI. R2 remains open until the required currency legs, original value identity, availability and expectations have their own proof.
