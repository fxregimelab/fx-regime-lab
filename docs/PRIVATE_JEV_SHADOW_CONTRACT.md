## Evidence interface

`capture_evidence(url: str, source: str, root: Path, *, publication: str | None = None) -> dict[str, Any]` returns an immutable local receipt or a visible UNAVAILABLE record. Only the seven official central-bank publisher/host pairs are permitted. HTTPS, no userinfo/nonstandard port, no arbitrary redirected host, bounded body <=2MiB and bounded request time; keep raw bytes and a real post-fetch UTC receipt. Do not use a proxy body as an original bank capture. Supplied publication is a declared publisher-feed claim, not an article-verified clock or historical arrival; preserve that distinction and unknown vintage.

`verify_evidence(receipt: dict[str, Any], root: Path) -> dict[str, Any]` replays raw hash, constrained local paths, publisher-specific extraction, extracted UTF-8 byte hash and spans. Return the verified receipt plus `text` and `spans`. `derive_spans(text: str) -> list[dict[str, Any]]` produces bounded deterministic paragraph chunks, exact UTF-8 extracted-text offsets and stable IDs. The offset basis must explicitly be UTF8_EXTRACTED_TEXT; raw HTML and extracted text are different bytes. Re-extraction must reproduce the text, so fabricated text/spans cannot survive raw-source replay. Article/main selectors and extraction coverage are declared, never promoted to a perfect full-document claim.

Reject login/challenge/error/empty pages and unsupported content/encoding instead of mining navigation as article evidence. Save failed raw captures where available. Original receipt/raw/text files stay immutable. A canonical bounded manifest may refer to captures under the evidence root; no writes to the current report. Source worker may capture at most twelve public documents in .private-fx/evidence, using witnessed links from the latest report and a documented RBNZ discovery link if reachable. Use old documents only as retrospective semantic examples, never fresh current evidence. Report source/date/parser limits and actual successes/failures; no target count is invented.
